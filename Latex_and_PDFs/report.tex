\begin{abstract}
Music Source Separation (MSS) aims to isolate individual instrument stems from mixed audio recordings. This project implements and compares two neural network architectures for spectrogram-based vocal separation: a U-Net encoder-decoder and an LSTM-based baseline. Both models operate on log-magnitude spectrograms and employ curriculum learning across two stages (2→1 and 4→1 source separation). Our results demonstrate that the U-Net architecture outperforms the LSTM baseline in terms of separation quality metrics (SDR, SIR, SAR). We additionally propose future extensions including attention mechanisms and cross-singer voice transfer techniques.
\end{abstract}

\section{Introduction}

\subsection{Problem Statement}
Music Source Separation (MSS) is the task of decomposing a mixed audio signal into its constituent sources (vocals, drums, bass, etc.). This has applications in music production, remixing, karaoke generation, and music information retrieval.

\subsection{Our Approach}
We implement and compare two frequency-domain (spectrogram-based) neural architectures:
\begin{enumerate}
    \item \textbf{U-Net (Our Implementation):} A 2D convolutional encoder-decoder with skip connections
    \item \textbf{LSTM (Baseline from Literature):} A bidirectional LSTM with soft masking, adapted from prior work in spectrogram-based source separation
\end{enumerate}

\subsection{Overall Pipeline}
Both models follow the same general approach:
\begin{enumerate}
    \item Convert audio waveform to \textbf{log-magnitude spectrogram} via STFT
    \item Feed spectrogram through neural network to predict a \textbf{soft mask}
    \item Apply mask in \textbf{linear domain}: $\hat{S}_{\text{linear}} = M \cdot \exp(X_{\text{log}})$
    \item Convert back to \textbf{log domain} for loss computation: $\hat{S}_{\text{log}} = \log(1 + \hat{S}_{\text{linear}})$
    \item Compute MSE loss: $\mathcal{L} = \text{MSE}(\hat{S}_{\text{log}}, Y_{\text{log}})$
    \item Reconstruct waveform via inverse STFT using original phase
\end{enumerate}

This approach (masking in linear domain, loss in log domain) balances numerical stability with perceptual quality.

\subsection{Model Architectures}

\subsubsection{Model A: U-Net (Our Implementation)}
\textbf{Architecture:}
\begin{itemize}
    \item 5-layer encoder-decoder with skip connections
    \item Base filters: 32, doubled at each downsampling layer
    \item Batch normalization and dropout (p=0.1) for regularization
    \item Input/Output: [Batch, 1, Freq, Time] spectrograms
    \item Parameters: $\sim$1.2M
\end{itemize}

\textbf{Strengths:}
\begin{itemize}
    \item Skip connections preserve high-frequency details
    \item 2D convolutions capture local time-frequency patterns
    \item Well-suited for image-like spectrogram data
\end{itemize}

\subsubsection{Model B: LSTM (Baseline from Literature)}
\textbf{Architecture:}
\begin{itemize}
    \item 2-layer bidirectional LSTM
    \item Hidden size: 512 per direction (1024 total)
    \item Dropout (p=0.3) between LSTM layers
    \item Input: Flattened frequency bins per time step
    \item Output: Soft mask reshaped to spectrogram dimensions
    \item Parameters: $\sim$800K
\end{itemize}

\textbf{Strengths:}
\begin{itemize}
    \item Models temporal dependencies explicitly
    \item Bidirectional context captures past and future frames
    \item Fewer parameters than U-Net
\end{itemize}

\textbf{Attribution:} This baseline architecture is adapted from the work presented in ``Source Separation \& Automatic Transcription,'' which proposed using LSTM networks for spectrogram-based music source separation. We implemented our own version and compared it against our U-Net design.

\section{Dataset \& Training}

\subsection{MUSDB18-HQ Dataset}
\begin{itemize}
    \item Standard benchmark for music source separation
    \item $\sim$150 professionally mixed tracks with isolated stems
    \item Stems: Vocals, Drums, Bass, Other
    \item Split: $\sim$100 train, $\sim$14 validation, $\sim$50 test
    \item Sample rate: Downsampled to 22.05 kHz for computational efficiency
\end{itemize}

\subsection{Curriculum Learning Strategy}
We employ a two-stage curriculum to improve convergence:

\textbf{Stage 1: Simplified Task (2 → 1 sources)}
\begin{itemize}
    \item Input: Mixture of vocals + one random instrument (drums, bass, or other)
    \item Target: Isolated vocals
    \item Goal: Learn basic separation in a less crowded mixture
    \item Chunk duration: 8 seconds with 4-second overlap
\end{itemize}

\textbf{Stage 2: Full Complexity (4 → 1 sources)}
\begin{itemize}
    \item Input: Full mixture (vocals + drums + bass + other)
    \item Target: Isolated vocals
    \item Initialization: Models warm-started with Stage 1 weights
    \item Goal: Handle realistic separation scenarios
\end{itemize}

\subsection{Training Configuration}
\begin{itemize}
    \item Optimizer: Adam (lr=0.001)
    \item Loss function: MSE in log domain
    \item Batch size: LSTM=128, U-Net=32 (due to memory constraints)
    \item Early stopping: Patience of 5 epochs on validation loss
    \item Hardware: NVIDIA GPU with CUDA support
\end{itemize}

\section{Experimental Results}

\subsection{Evaluation Metrics}
We evaluate models on the held-out test set using the \texttt{museval} library:
\begin{itemize}
    \item \textbf{SDR (Signal-to-Distortion Ratio):} Overall separation quality (higher is better)
    \item \textbf{SIR (Signal-to-Interference Ratio):} Suppression of interfering sources (higher is better)
    \item \textbf{SAR (Signal-to-Artifacts Ratio):} Absence of artifacts/distortion (higher is better)
\end{itemize}

\section{Future Work}

\subsection{Phase 2: Attention Mechanism Enhancement}
\textbf{Motivation:} Multi-head self-attention can capture long-range dependencies better than LSTMs, potentially improving separation of repetitive musical structures (drum patterns, bass lines).

\textbf{Proposed Architecture:}
\begin{itemize}
    \item Integrate multi-head self-attention into U-Net bottleneck
    \item Add positional encodings to preserve temporal information
    \item Compare: U-Net vs U-Net+Attention vs LSTM
\end{itemize}

\textbf{Expected Benefits:}
\begin{itemize}
    \item Global receptive field across entire spectrogram
    \item Improved modeling of periodic structures
    \item Better handling of polyphonic content
\end{itemize}

\subsection{Phase 3: Cross-Singer Voice Transfer}
\textbf{Goal:} Generate vocal stems with different singers' characteristics while preserving melody and lyrics.

\textbf{Example Applications:}
\begin{itemize}
    \item Mark Knopfler singing a Beatles song (A→B)
    \item The Beatles covering a Mark Knopfler song (B→A)
\end{itemize}

\textbf{Proposed Approach:}
\begin{enumerate}
    \item \textbf{Step 1:} Use trained MSS model to extract vocals from both artists' songs
    \item \textbf{Step 2:} Train voice conversion model (CycleGAN, AutoVC, or similar) on extracted vocals
    \item \textbf{Step 3:} Apply conversion to generate cross-singer renditions
    \item \textbf{Step 4:} Remix converted vocals with original accompaniment
\end{enumerate}

\textbf{Evaluation:}
\begin{itemize}
    \item Subjective listening tests for quality and identity preservation
    \item Objective metrics: MCD (Mel-Cepstral Distortion), F0 correlation
    \item Comparison with baseline voice conversion approaches
\end{itemize}

\section{Conclusion}
We implemented and compared two neural architectures for music source separation: a U-Net encoder-decoder and an LSTM baseline adapted from prior work. Both models operate on log-magnitude spectrograms and employ curriculum learning. Our preliminary results indicate that U-Net outperforms LSTM on standard BSS metrics, demonstrating the effectiveness of convolutional architectures with skip connections for spectrogram-based separation.

Future work will explore attention mechanisms for improved long-range modeling and cross-singer voice transfer for creative music production applications.
