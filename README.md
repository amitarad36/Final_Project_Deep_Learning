# Deep Music Source Separation
**Winter 2026 Final Project - Deep Learning on Computational Accelerators**

---

## How to Run

1. **Create and activate the environment:**
   ```bash
   conda env create -f environment.yml
   conda activate final-dl-env
   ```

2. **Run the notebook:**
   - Open `mainNB.ipynb`
   - Run all cells sequentially
   - To test the models on your own song, place an audio file (e.g., `.wav` or `.mp3`) in the `data/user_uploads/` directory before running the notebook. The notebook includes code to process custom audio files.

---

## What's Included

- **`mainNB.ipynb`** - Interactive main notebook
- **`models/`** - Model architectures (models.py) and utilities (utils.py)
- **`checkpoints/`** - Pre-trained models' weights
- **`data/`** - Preprocessed audio chunks (one demo song from test set)
